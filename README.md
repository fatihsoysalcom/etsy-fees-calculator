# Etsy Fees Calculator

This Python script calculates estimated Etsy fees for sales in the UK, EU, Canada, and Australia. It demonstrates how different regions have varying listing fees and fixed payment processing fees, while transaction and percentage-based payment processing fees are generally consistent.

## Language

`python`

## How to Run

Save the code as `etsy_fees.py` and run it from your terminal using `python etsy_fees.py`.
